Coordinate conventions

XYZ: metres. Roll, pitch, yaw: degrees, fixed-axis XYZ (Rz × Ry × Rx). Mounts map sensor body coordinates into the project reference frame.

Optical axes: x right, y down, z forward. LiDAR mounts remain fixed. Downloads include both transform directions.
